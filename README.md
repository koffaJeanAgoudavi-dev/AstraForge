# AstraForge — AI Software Engineer

Autonomous multi-agent AI software engineer for building, testing, deploying, and managing applications. Rewritten as a modern React application with Vite, TypeScript, and Tailwind CSS.

## Features

- **Autonomous Multi-Agent Pipeline**:
  - **01 Architect**: Problem decomposition, architecture specification, and contract planning.
  - **02 Developer**: Full source generation across web, SaaS, and app components.
  - **03 Tester**: Automated sandbox testing and quality gate checks.
  - **04 Reviewer**: Quality review, security audit, and repair loop verification.
- **Interactive Workbench**:
  - Live project generation with preset modes (Web, SaaS, App) and custom briefs.
  - Real-time build logs terminal with status indicators.
  - Workspace file tree and code inspector with copy/download.
  - Live interactive sandbox preview with desktop and mobile viewports.
- **Multi-Model Provider Router**:
  - Role-based fallback routing across Gemini, DeepSeek, Cerebras, Groq, Mistral, and OpenAI.
  - Configurable sampling temperatures and priority orders.
- **Deployment & Publish Integrations**:
  - GitHub Pull Request publishing configuration.
  - Cloudflare Pages deployment pipeline.

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
